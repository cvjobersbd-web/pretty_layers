# Pretty Layers — মেয়েদের ফ্যাশন ই-কমার্স সাইট (HTML + PHP)

*Wrapped in sweet dreams*

## ইনস্টল করার নিয়ম

### XAMPP (নিজের কম্পিউটারে)
1. পুরো `lavanya` ফোল্ডারটা `C:\xampp\htdocs\` এর ভেতরে রাখুন।
2. XAMPP Control Panel থেকে **Apache** আর **MySQL** চালু করুন।
3. ব্রাউজারে খুলুন: `http://localhost/lavanya/install.php`
4. অ্যাডমিন ইউজারনেম আর পাসওয়ার্ড দিয়ে **Install now** চাপুন। ডাটাবেস (`pretty_layers`) নিজে থেকেই তৈরি হয়ে যাবে।
5. ইনস্টল শেষ হলে `install.php` ফাইলটা ডিলিট করে দিন।

### cPanel হোস্টিং
1. cPanel → **MySQL Databases** থেকে একটা ডাটাবেস আর ইউজার তৈরি করুন।
2. `config.php` খুলে `DB_NAME`, `DB_USER`, `DB_PASS` বদলে দিন।
3. সব ফাইল `public_html` এ আপলোড করুন, তারপর `yourdomain.com/install.php` খুলুন।
4. `uploads/` আর `data/` ফোল্ডারে লেখার অনুমতি (permission 755 বা 775) থাকতে হবে।

### MySQL ছাড়া (SQLite)
`config.php` তে `'mysql'` এর জায়গায় `'sqlite'` লিখুন। কোনো ডাটাবেস সেটআপ লাগবে না।

## অ্যাডমিন প্যানেল
`http://localhost/lavanya/admin/`

| মেনু | কাজ |
|---|---|
| Dashboard | আজকের ও মাসের বিক্রি, লাভ, পেন্ডিং অর্ডার, স্টকের মূল্য, low stock alert, ১৪ দিনের বিক্রির চার্ট |
| Products | প্রোডাক্ট যোগ, এডিট, ডিলিট, লুকানো আর Featured করা। মেইন ছবি আর গ্যালারির ছবি আপলোড |
| Categories | ক্যাটাগরি যোগ ও এডিট, ছবিসহ |
| Orders | সব অর্ডার, স্ট্যাটাস বদলানো, ইনভয়েস প্রিন্ট |
| Customers | রেজিস্টার করা কাস্টমারদের তালিকা, তাদের অর্ডার ও মোট কেনাকাটা, পাসওয়ার্ড রিসেট |
| Inventory | সাইজ আর কালার অনুযায়ী স্টক, Restock / Remove / Set, low ও out of stock ফিল্টার, CSV এক্সপোর্ট |
| Stock History | স্টকের প্রতিটা পরিবর্তনের রেকর্ড |
| Settings & Design | সাইটের নাম, লোগো, লোডিং অ্যানিমেশন, পুরো সাইটের কালার, ডেলিভারি চার্জ, bKash/Nagad নম্বর, পাসওয়ার্ড |

## কাস্টমার অ্যাকাউন্ট
- `login.php` আর `register.php`: মোবাইল নম্বর বা ইমেইল দিয়ে লগইন, মোবাইল নম্বর দিয়ে সাইন আপ।
- `account.php`: নিজের অর্ডার ও তার স্ট্যাটাস, প্রোফাইল ও ঠিকানা, পাসওয়ার্ড বদলানো।
- লগইন করা থাকলে চেকআউটে নাম, ফোন আর ঠিকানা নিজে থেকে বসে যায়। লগইন ছাড়াও অর্ডার করা যায়।
- কেউ পাসওয়ার্ড ভুলে গেলে অ্যাডমিন → Customers থেকে নতুন পাসওয়ার্ড তৈরি করে দিন।

## প্রোডাক্টে একাধিক ছবি
অ্যাডমিন → Products → Add / Edit:
- **Main image**: প্রধান ছবি, শপ পেজ আর কার্ডে এটাই দেখায়।
- **Gallery images** → "Add more images": একসাথে একাধিক ছবি বেছে নিন (Ctrl চেপে ধরে)। প্রোডাক্ট পেজে ছবিগুলো ছোট থাম্বনেইল হিসেবে দেখাবে।
- পুরোনো ছবি সরাতে ছবির নিচে "remove" টিক দিয়ে Save করুন।

## ইনভেন্টরি কীভাবে কাজ করে
- কাস্টমার অর্ডার করলে স্টক নিজে থেকেই কমে যায়।
- অর্ডার **Cancelled** করলে স্টক আবার যোগ হয়।
- স্টক শূন্য হলে সাইটে "Sold out" দেখায় আর কেউ কিনতে পারে না।
- স্টক "Low stock alert" সংখ্যার নিচে নামলে ড্যাশবোর্ডে সতর্কবার্তা আসে।

## ফোল্ডারের গঠন
```
config.php          ডাটাবেস সেটিং
install.php         একবার চালানোর ইনস্টলার
index.php, shop.php, product.php, cart.php, checkout.php, track.php
admin/              অ্যাডমিন প্যানেল
assets/css, js, img স্টাইল, স্ক্রিপ্ট, ডেমো ছবি
uploads/            আপলোড করা ছবি আর লোগো
includes/           শেয়ার করা PHP কোড
```

প্রয়োজন: PHP 8.0 বা তার নতুন ভার্সন, PDO MySQL extension (XAMPP-তে আগে থেকেই থাকে)।
